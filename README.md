# Lightning Web Components

Salesforce development project demonstrating Lightning Web Components (LWC), Apex, component communication, and Salesforce metadata.

## Overview

This repository contains a collection of Salesforce development work centered on Lightning Web Components and their interaction with Apex and Salesforce platform features.

## What It Demonstrates

- Lightning Web Components with JavaScript, HTML, and CSS
- Apex classes used with Salesforce UI components
- Communication between Lightning components using Lightning Message Channels
- Salesforce page and component configuration
- Static resources and Salesforce metadata
- Organizing Salesforce development artifacts into deployable project structure

## Repository Structure

- `lwc/` — Lightning Web Components
- `classes/` — Apex classes
- `messageChannel/` — Lightning Message Channel metadata
- `pageComponents/` — page/component configuration
- `pages/` — Salesforce page metadata
- `staticResources/` — static resources used by the project

## Technologies

- Salesforce
- Lightning Web Components (LWC)
- Apex
- JavaScript
- HTML
- CSS
- Salesforce Metadata

## Context

This project was developed as part of Salesforce-focused software development practice and complements hands-on experience with Apex and Salesforce platform development.
